# Publicación gratuita en Streamlit Community Cloud

1. Iniciar sesión en https://share.streamlit.io/ con GitHub.
2. Seleccionar **Create app** > **Deploy a public app from GitHub**.
3. Repositorio: `ibanezmariela78-lab/labdata-analytics`.
4. Rama: `main`. Archivo principal: `app.py`.
5. Pulsar **Deploy** y esperar el resultado.

La aplicación usa datos sintéticos, no necesita base de datos, claves ni servicios pagos para esta demostración. La disponibilidad del servicio gratuito depende de las condiciones de Streamlit.

Si falla, revisar los logs del despliegue. Antes de compartir el enlace, confirmar que gráficos y descarga CSV funcionen.
