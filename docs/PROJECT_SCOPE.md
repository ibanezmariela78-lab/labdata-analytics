# DataVision AI — Laboratory Intelligence

Proyecto de ciencia de datos para laboratorios químicos, farmacéuticos y biotecnológicos.

## Objetivos
- Arquitectura de datos, ETL y calidad.
- PostgreSQL, SQL y modelado dimensional.
- Análisis estadístico y Machine Learning.
- Dashboards interactivos con Streamlit, Plotly y Power BI.
- Casos de control de calidad, inventarios y producción con datos sintéticos.
